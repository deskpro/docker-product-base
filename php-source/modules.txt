# Shared PHP extensions produced by the source build (PHP_INSTALL_METHOD=source).
#
#   <module> <priority> [zend]
#
# Each module with a numeric priority gets /etc/php/8.3/mods-available/<module>.ini
# and is enabled for every SAPI with phpenmod, exactly as the Debian (sury)
# packages do it. The priorities are the ones those packages use, so the
# conf.d/NN-<module>.ini load order -- and any operator override that relies
# on it -- is unchanged.
#
# A priority of "-" means the module is built here but its .ini is written by
# the Dockerfile's shared stage2 step, the same as for PHP_INSTALL_METHOD=deb.
#
# build.sh fails if a built .so is missing from this table, or a listed one
# was not built.
